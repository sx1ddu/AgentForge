# Visual references

Open `index.html` directly in a modern browser. It is a self-contained, responsive HTML/CSS/JS concept prototype with a screen switcher represented by the left navigation and clickable page links. It includes: Landing, Login, Onboarding, Workspace, Agent Library, Conversation, Team Run, Artifact, Billing and Settings.

The prototype is a visual design artifact, not a production app. Interactive controls that depend on Firebase, API calls, downloads or Stripe show a toast explaining the integration boundary; they do not pretend to complete backend actions. Text and sample code are illustrative. The Team Run view explicitly distinguishes graph structure from live telemetry.
