# Settings

**Sections:** Profile (name/email/avatar read-only from user object), Appearance (dark/light local preference only), Keyboard shortcuts (Cmd/Ctrl+K, Cmd/Ctrl+N, Enter/Shift+Enter), Account (logout). Billing link navigates to billing.

**Do not include:** password reset, connected-app management, API keys, notification preferences, account deletion, security sessions or server-synced preferences; no supporting frontend/backend contracts were found.

**Layout:** left in-page section list, right 640 px content column. On mobile use segmented select/stacked sections. Save feedback only for preferences actually persisted locally.
