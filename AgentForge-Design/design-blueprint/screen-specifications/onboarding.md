# Onboarding

**Classification:** proposed frontend-only walkthrough; no onboarding persistence endpoint exists.

**Maximum:** three dismissible steps, skip always visible.
1. “Choose how work starts” — Auto routes request; Team invokes planner/researcher/coder/reviewer graph; specialist modes target one capability.
2. “Add context” — prompt and optional single file; PDF/image attachment can auto-route in Auto mode.
3. “Inspect the result” — final response and available artifacts; code is read-only, copy/download, HTML preview when supported.

Show one sample task and take user to composer. Store completion locally only if product approves local storage; do not claim synced onboarding.
