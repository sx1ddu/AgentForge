# Responsive design

## Breakpoints
- <640: mobile; navigation drawer, one-column canvas, artifact full-screen sheet.
- 640–767: large mobile; composer width 100%, compact header.
- 768–1023: tablet; sidebar collapses to rail; inspector overlays as sheet.
- 1024–1279: desktop; rail + 220 px sidebar + canvas; inspector overlays or 360 px panel.
- 1280+: full 56 + 248 + flexible + 420 layout.

## Touch
Minimum 44×44 px interactive targets on touch devices. Do not require hover. Context menu has visible alternative row action. Composer action buttons remain reachable with keyboard and touch.

## Landing
Mobile nav: brand + menu + CTA; hero stacks; product preview becomes horizontally scrollable or vertically simplified; no tiny multi-column diagrams.

## Workspace
At narrow widths, hide secondary metadata before shrinking message text. Conversation sidebar becomes drawer. Artifact inspector takes full viewport with explicit Back to conversation.
