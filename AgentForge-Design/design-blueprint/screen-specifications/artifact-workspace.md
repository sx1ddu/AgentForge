# Artifact workspace

**Purpose:** inspect generated source and collect files.

**Current contract:** `artifacts[]`; UI reads first artifact, `artifact.files[]` with `name` and `content`. Monaco is read-only. Preview requires `index.html`; CSS from `style.css`, JS from `script.js` are inlined in sandboxed iframe. Copy/download acts on active file.

**Desktop:** right inspector 420 px. Header with artifact title, file count, Code / Preview only if supported, copy/download. File tabs. Source pane. Avoid false Save, Edit, Run, Deploy, version history controls.

**Other formats:** PDF/PPT artifacts may be generated by backend, but this component's current viewer is not a PDF/PPT previewer. Provide download/open only when the actual artifact data shape and URL are verified; otherwise show the returned output link or a clearly stated unsupported preview.

**Mobile:** full-screen sheet with file picker and close. Maintain active file when resizing.
